# Dynamic Event Scheduling & Conflict Resolver

An enterprise-grade production REST API & Interactive Dashboard for scheduling optimization, multi-dimensional conflict detection, what-if simulations, and automated resolution.

## Production Features
- **OAuth 2.0 / OpenID Connect**: Real, production-grade authentication with Google, GitHub, and Microsoft.
- **Smart Optimizer**: Generates alternative non-conflicting time slots ranked by weighted optimization criteria.
- **Conflict Center**: Multi-dimensional conflict detection and 1-click automatic resolution.
- **What-If Simulation Drawer**: Test schedule changes with dry-run compatibility scoring.
- **Real-Time Analytics & Audit Log**: Dynamic metrics and historical change logs.
